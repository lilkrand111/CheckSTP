# CheckSTP

CheckSTP проверяет оформление курсовых, пояснительных записок и другой технической документации в формате DOCX по профилю СТП 01–2017 с согласованными уточнениями.

## Возможности

- Проверка полей и формата страницы, шрифтов, абзацев, заголовков, подписей и нумерации. В отчёте есть описание замечания, место в документе и основание проверки.
- Поиск, фильтры и отметки «Исправлено» в отчёте. Замечания разделены на ошибки, ручные проверки и рекомендации.
- Автоисправление поддерживаемых нарушений оформления, включая отдельные нарушения полей, отступов и интервалов. Сервис создаёт отдельную копию и повторно проверяет её перед скачиванием.

Проверка опирается на структуру и свойства DOCX. Содержание работы, текст на изображениях и итоговая вёрстка страниц требуют ручного просмотра. Пустой отчёт означает, что в пределах выполненных проверок замечаний нет.

## Локальный запуск

Понадобится Python 3.12. FastAPI обслуживает интерфейс и API. HTML, CSS и JavaScript доступны сразу после запуска.

```bash
git clone https://github.com/lilkrand111/normacheck.git checkstp
cd checkstp

python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.lock
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 1 --no-access-log --log-level critical
```

Откройте [интерфейс CheckSTP](http://127.0.0.1:8000/), выберите DOCX и нажмите «Проверить документ». Из отчёта можно запустить автоисправление и скачать повторно проверенную копию. По умолчанию максимальный размер загрузки составляет 20 МиБ. Его задаёт переменная `MAX_UPLOAD_MB`.

Проверить состояние сервера можно по адресу [/health](http://127.0.0.1:8000/health).

## Обработка файлов

В веб-режиме сервер обрабатывает DOCX и отчёты в оперативной памяти в рамках запроса. Исходник, отчёт, отметки и исправленная копия находятся в памяти вкладки браузера. После обновления страницы файл нужно выбрать заново.

Один процесс Uvicorn координирует дочерние обработчики. По умолчанию одновременно обрабатываются до двух документов. Настройка `MAX_CONCURRENT_JOBS` задаёт этот предел.

## Проверка из терминала

Из корня репозитория укажите путь к своему DOCX. Команды CLI записывают результаты в файлы, указанные через `--output`.

```bash
.venv/bin/python -m formal_check document.docx --output report.json
.venv/bin/python -m formal_fix document.docx --output corrected.docx
.venv/bin/python -m formal_check corrected.docx --output corrected-report.json
```

## Устройство проекта

| Каталог | Назначение |
| --- | --- |
| [`app/`](app/) | FastAPI, сессии, контроль загрузок и запуск дочерних обработчиков |
| [`frontend/`](frontend/) | Веб-интерфейс загрузки, проверки и просмотра отчётов |
| [`formal_check/`](formal_check/) | Чтение DOCX, правила оформления и формирование отчёта |
| [`formal_fix/`](formal_fix/) | Автоисправление поддерживаемых замечаний |
| [`tests/`](tests/) | Тесты API, правил оформления и интерфейса |

## Развёртывание

На VPS приложение запускается через Docker Compose с Caddy. Перед публичным запуском проверьте настройки хоста, памяти и журналов.

## Тесты

```bash
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m pytest tests -q
```

Для тестов JavaScript нужен Node.js 22 или новее.

```bash
node --test tests/frontend*.test.mjs
```
