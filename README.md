# NormaCheck

NormaCheck проверяет оформление курсовых, пояснительных записок и другой технической документации в формате DOCX по профилю СТП 01–2017 с согласованными уточнениями.

## Возможности

- Проверка полей и формата страницы, шрифтов, абзацев, заголовков, подписей и нумерации. Для найденных замечаний отчёт указывает место в документе и основание проверки.
- Адаптивный веб-интерфейс с поиском, фильтрами и личными отметками «Исправлено». В отчёте выделены ошибки, места для ручной проверки и рекомендации.
- Автоисправление поддерживаемых нарушений, например неверных полей, отступов и межстрочных интервалов. Исходник сохраняется без изменений. Исправленная копия доступна для скачивания после повторной проверки.

Проверка опирается на структуру и свойства DOCX. Содержание работы, текст на изображениях и итоговая вёрстка страниц требуют ручного просмотра. Пустой отчёт означает, что в пределах выполненных проверок замечаний нет.

## Локальный запуск

Понадобится Python 3.12. FastAPI обслуживает интерфейс и API, поэтому для запуска сайта достаточно одного сервера. Интерфейс написан на HTML, CSS и JavaScript без сборки.

```bash
git clone https://github.com/lilkrand111/normacheck.git
cd normacheck

python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.lock
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 1
```

Откройте [http://127.0.0.1:8000/](http://127.0.0.1:8000/), выберите DOCX и нажмите «Проверить документ». По умолчанию можно загрузить файл размером до 20 МиБ.

Для диагностики доступны [проверка состояния сервера](http://127.0.0.1:8000/health) и [схема OpenAPI](http://127.0.0.1:8000/openapi.json).

## Проверка из терминала

Команды выполняются из корня репозитория после установки зависимостей. Укажите путь к своему DOCX.

```bash
.venv/bin/python -m formal_check document.docx --output report.json
.venv/bin/python -m formal_fix document.docx --output corrected.docx
.venv/bin/python -m formal_check corrected.docx --output corrected-report.json
```

## Устройство проекта

| Каталог | Назначение |
| --- | --- |
| [`app/`](app/) | FastAPI, сессии, файловое хранилище и запуск дочерних обработчиков |
| [`frontend/`](frontend/) | Веб-интерфейс загрузки, проверки и просмотра отчётов |
| [`formal_check/`](formal_check/) | Чтение DOCX, правила оформления и формирование отчёта |
| [`formal_fix/`](formal_fix/) | Автоисправление поддерживаемых замечаний |
| [`tests/`](tests/) | Тесты API, правил оформления и интерфейса |

Данные хранятся на диске без базы данных. Принятые исходники, исправленные копии и отчёты сохраняются в `storage/documents/<uuid>/` без ограничения срока. Доступ через API привязан к подписанной cookie анонимной сессии. Один процесс Uvicorn координирует обработку нескольких документов параллельно. Число дочерних обработчиков задаётся переменной `MAX_CONCURRENT_JOBS` и по умолчанию равно двум.

## Тесты

```bash
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m pytest tests -q
```

Для тестов JavaScript нужен Node.js 22 или новее.

```bash
node --test tests/frontend*.test.mjs
```
